03 / CONNECT IN YOUR OWN ENVIRONMENT

    
Your agent.
One shared checker.
Run TINT locally with Python 3.11+. The MCP server supplies tools; the portable skill guides the review. No API key or GPU is needed by TINT.

    
01 / INSTALL THE SERVER
Clone. Create an environment.
Use a separate environment to keep research dependencies and agent tooling distinct.
git clone https://github.com/ai4se4ai-lab/trust-is-not-transitive.git
cd trust-is-not-transitive
python -m venv .venv
.venv/bin/python -m pip install -e ".[mcp]"
Install from source; no published PyPI package is assumed. Pin a repository commit when reproducing results.

    
02 / REGISTER THE MCP SERVER
Choose your client.
Use the absolute interpreter path printed below. It keeps the server available when the agent opens a different project.
codex mcp add tint -- /absolute/path/to/.venv/bin/python -m tint.mcp.server
codex mcp list
Replace the example interpreter path with your actual absolute path.

    
03 / ADD THE REVIEW WORKFLOW
Install the complete skill folder.
Copy skills/tint-review/ from the clone to your target project's .agents/skills/ for Codex or .claude/skills/ for Claude Code. Keep its references and metadata. The skill and server are installed separately.
Restart your agent session and ask:
Use tint-review to check our guardrail pipeline. Show the model, explain any counterexample, propose a repair and recheck. List the assumptions that remain.

Know what a passing check means.
It establishes composition under the declared premises. It does not prove a learned guard accurate, validate calibration, or enforce the agent's actions. A deterministic gate remains a claim about a real implementation.
The local service accepts up to 128 nodes and 32 goals, layers and obligations each, with a 128 KiB input limit and a 10-second analysis timeout. An error or timeout means no verdict. Provided facts can require exponential analysis.
The research study evaluates the calculus and its implementation. This integration does not establish effectiveness on live agents. Runtime protection requires a trusted host and complete mediation.

  

  
05 / BEFORE YOU START
A few practical questions.

    
Do I need to move my agent into this repository?
No. Install the server once in its own clone, register its absolute Python path, and copy the skill into the project you want to review. Supply a model of that project's pipeline through the MCP tools.

    
Can I paste a prompt and ask whether it is safe?
TINT is a checker for declared guardrail composition. It is not a prompt classifier. Your agent first needs an explicit model of goals, contracts, evidence and routing.

    
Does the fallback repair prove that the reviewers are reliable?
No. It makes the required evidence explicit at both invocations. The repaired example still assumes the contracts hold there. Inspect the residual assumptions in the report.

    
Is there a public hosted MCP endpoint?
This release supplies a local stdio server. GitHub Pages hosts these instructions and examples. Public HTTP hosting would need a separate service with authentication, resource controls and deployment operations.

    
How do I check my own architecture?
Describe the policy goals, each guard's contract, the evidence supporting it and all branches. Ask your agent to follow tint-review, show you its HSL mapping, call the checker and explain the remaining assumptions.
