# Controlled terminology

- conditioned trust: reliance on a named property's verdict under discharged premises
- joint unsafe acceptance / residual risk: Pr(unsafe AND allow), denominator all decisions
- attack success: Pr(allow | unsafe); not interchangeable with residual risk
- attack miss rate: the same conditional event, named from the guard's perspective
- benign utility: benign acceptance, a fixture proxy rather than real task completion
- early-acceptance cascade: disjoint terminal acceptance routes
- all-veto ensemble: every guard must allow
- quarantine: closed structured projection excluding raw issue/target/rationale strings
- whole-policy certificate: certificate for the actual fixed routing policy, not local marginal errors
- route-specific bounds: theoretical disjoint acceptance-event bounds; not separately estimated in the pilot
- calibration confidence: probability over calibration samples that a population bound holds
- CRC guarantee: marginal expected risk, not the preceding confidence statement
- common-shock mixture weight: model parameter; not generic observed pairwise correlation
- primary: frozen original study with historical lexical arithmetic
- exploratory: separately labeled fresh-seed numeric-correction replication
- modeled cost units: arbitrary configured units; never prices, tokens or measured milliseconds
- complete mediation: every typed effect passes mandatory sink predicates
- typed sandbox: in-memory interpreter with no OS shell or network client
- primary scorer: frozen lexical-v1 with historical floating-point expression
- exploratory scorer: frozen lexical-v2 with integer-hundredths arithmetic
- current scorer: lexical-v3-bounded; historical timings/certificates do not describe it

Proof names, mathematical symbols and their scopes: `formal/notation.json` and
`formal/FRAMEWORK.md`. Guard/model versions identify scripted components only.
